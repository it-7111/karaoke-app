# カラオケ帳

歌える曲のリストとカラオケの点数を記録する iPhone / iPad 用 Web アプリ（PWA）。
オフラインで動き、オンラインになると Google スプレッドシートと双方向に同期します。

## できること

- 曲リスト：検索（かな・カタカナ・歌手名）、状況/原キーで音域内/キー変更で歌える/PDFあり/歌った・未歌唱で絞り込み、平均点・最高点・回数・最近順で並び替え
- キー判定：曲の原キー最低音・最高音と自分の音域から「♭2で歌える」「オク下で歌える」などを自動表示（キー変更は ±7 まで）
- セトリ：その日に歌う曲を並べて、曲順の入れ替え・歌ったチェック。セトリから点数を記録すると自動で✓が付く
- 選曲：条件（状況OK・キー変更で歌える・未歌唱）付きのランダム選曲、セトリ最後の曲から続けるしりとり候補、検索
- 練習録音：曲ごとにその場で録音、または音声ファイルを追加。オフライン再生可、ドライブにも保管
- 点数記録：日付・機種（Dx/Ai/WAO/JoyAI）・総合得点・ボーナス点・キー・コメント、チャート（音程・ビブラート&ロングトーン・リズム・表現力・安定性・聴感〈WAO＝Ai-Heartのみ〉）と抑揚。チャート合計と素点（総合得点 − ボーナス点）は自動計算
- 曲ごとの成績：回数・平均・最高・最低、点数推移グラフ、機種別平均
- ディレクション・歌詞解釈：曲ごとに PDF やテキストを複数添付。テキストはアプリ内で書いて編集でき、.txt / .md ファイルの取り込みも可。端末内に保存されるのでオフラインでも閲覧可。Google ドライブにも保管され、もう一方の端末へ自動で届く
- 統計：点数分布、月別の歌唱回数、平均点・最高点・最低点のランキング（3回以上の曲に絞り込み可）、よく歌う曲（機種別にも切替可）
- バックアップ：曲・点数・セトリを JSON に書き出し / 読み込み
- iPad の横向きでは一覧と詳細を並べて表示

## データの保管場所

| 場所 | 中身 | 役割 |
|---|---|---|
| 端末内（IndexedDB） | 曲・点数・セトリ・PDF・録音 | オフラインで使うための本体 |
| スプレッドシート | 曲・点数 | 正本。両端末の合流点 |
| Google ドライブ「カラオケ帳_PDF」 | PDF・テキスト・練習録音 | 添付ファイルの正本 |
| `_app_pdfs` シート（非表示） | 添付ファイルの一覧 | どの曲にどのファイルがあるか |
| `_app_setlists` シート（非表示） | セトリ | セトリの正本（既存の「カラオケセトリ」タブには触れません） |

オフライン中の変更は端末内の「送信待ち」に溜まり、オンラインに戻ると自動で送られます（起動時・復帰時・変更の2秒後・5分ごと）。

### 同期のルール

- 変更は**項目単位**で送ります。iPhone で点数を、シートでコメントを直した場合、両方残ります
- 同じ項目を両方で変えた場合は、**後から同期した端末の変更**が残ります
- シートの **数式が入っているセルには一切書き込みません**（Ave/Max/Min、RANK、回数、ALL_RANK などはそのまま）
- 行の識別のため、「曲リスト」「カラオケ歌ったリスト」の右端に `_id` 列、「曲リスト」に `メモ(app)` 列が追加されます。`_id` 列は消さないでください
- シートで直接追加した行も、次の同期で `_id` が振られてアプリに取り込まれます
- 曲を新しく追加すると「番号」は最大値 + 1 が振られます
- セトリは1つのセトリ単位で、後から同期した端末の内容が残ります
- PDF・録音を削除すると、ドライブではゴミ箱に移るだけなので 30 日以内なら復元できます

## セットアップ

### 1. スプレッドシート側（Apps Script）

1. スプレッドシートを開き、念のため「ファイル → コピーを作成」でバックアップを取る
2. 「拡張機能 → Apps Script」を開き、`apps-script/Code.gs` の中身を貼り付けて保存
3. 上部の関数選択で `setup` を選んで「実行」→ 権限を許可（スプレッドシートとドライブへのアクセス）
4. 実行ログに出る **トークン** を控える
5. 「デプロイ → 新しいデプロイ」→ 種類「ウェブアプリ」、実行ユーザー「自分」、アクセスできるユーザー「全員」でデプロイし、**ウェブアプリの URL** を控える

「全員」にしても、トークンを知らない人は読み書きできません。トークンは他人に教えないでください。

`Code.gs` を後で更新したときは「デプロイを管理 → 編集 → バージョン: 新バージョン」で同じ URL のまま更新できます。

### 1-2. 「カラオケ歌ったリスト」の作り替え（評価項目の変更、一度だけ）

1. Apps Script に最新の `Code.gs` を貼り付けて保存
2. 関数 `migrateScoreSheet` を選んで実行（最初にスプレッドシート全体のコピーがドライブに作られます）
3. 列が次の並びになります（旧データの値は書き換えません）
   `総合得点`（旧 point）… `音程`（旧 音）`ビブラート&ロングトーン` `リズム` `表現力`（旧 表）`安定性` `聴感` `チャート合計` `抑揚`（旧 抑）`Ai/聴`（旧項目のまま）`素点` `ボーナス点`（旧 加点）
4. `チャート合計` と `素点` は1つの数式で全行を計算します。この2列には手で入力しないでください
5. 実行ログに「確認してください」と出た数式（他のシートの QUERY など）は、列がずれていないか確認する
6. 「デプロイ → デプロイを管理 → 編集 → バージョン: 新バージョン」で同期サーバーを更新

### 1-3. 「カラオケ点数リスト」に機種ごとの評価項目を足す（一度だけ）

1. Apps Script に最新の `Code.gs` を貼り付けて保存
2. 関数 `upgradeScoreSummary` を選んで実行（最初にスプレッドシート全体のコピーがドライブに作られます）
3. 全体・WAO・Ai・Dx の各ブロックが次の並びになります（聴感は全体と WAO のみ）
   `平均点` `最高点` `最低点` `音程` `ビブラート&ロングトーン` `リズム` `表現力` `安定性` `聴感` `チャート合計` `抑揚` `Ai/聴(旧)` `ボーナス点` `素点`
4. 列の挿入なので、「点数分布」や ALL_RANK などからの参照は自動で付け替わります
5. 「デプロイを管理 → 新バージョン」で同期サーバーを更新

アプリの「機種別の集計」（曲の詳細と統計タブ）は、同期した記録から同じ集計をアプリ内で計算します。オフラインでも表示され、記録した直後から反映されます。

### 1-4. WAO と他機種のチャートを比べる「500点換算」を足す（一度だけ）

WAO のチャートは6項目600点満点、他は5項目500点満点なので、合計のままでは比べられません。そこで `チャート合計 × 5 ÷ 項目数` を「500点換算」とします。例：WAO の 555 は 462.5、満点との差は 37.5。割合（92.5%）とは `換算 ÷ 5`、1項目あたりの失点（7.5）とは `差 ÷ 5` で対応します。全項目（WAO は聴感も）が入った記録だけ計算します。

1. `upgradeScoreSummary` を実行済みの状態で、最新の `Code.gs` を貼り付けて保存
2. 関数 `addChartScaled` を実行（最初にスプレッドシート全体のコピーが作られます）
3. 「カラオケ歌ったリスト」と「カラオケ点数リスト」の各ブロックで、チャート合計の右に `500点換算` が入ります
4. 「デプロイを管理 → 新バージョン」で同期サーバーを更新

### 2. アプリの公開（GitHub Pages）

このフォルダをリポジトリに置き、GitHub Pages を有効にします。コードに個人データやトークンは含まれていません（データは端末とスプレッドシートにだけあります）。

### 3. iPhone / iPad

1. Safari で公開した URL を開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから開き、「設定」タブで URL とトークンを入れて「保存して同期」

ホーム画面から開いた場合、iOS は端末内のデータを自動削除しません（Safari で開いただけの場合、7日間使わないと消されることがあります）。どちらの場合もスプレッドシートとドライブに正本があるので、消えても同期で戻ります。

## ファイル構成

```
index.html            画面の骨組み
styles.css            見た目（ライト/ダーク対応）
app.js                アプリ本体（保存・同期・画面）
sw.js                 オフライン用のキャッシュ
manifest.webmanifest  ホーム画面用の設定
icons/                アイコン
vendor/               PDF 表示ライブラリ（pdf.js 3.11.174）
apps-script/Code.gs   スプレッドシート側の同期サーバー
```
